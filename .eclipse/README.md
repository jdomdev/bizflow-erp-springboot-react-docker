# Eclipse / STS Configuration

This folder is reserved for IDE settings that the team explicitly decides to share. Do not copy Eclipse or STS workspace metadata here.

If you need to version a setting (for example, shared code templates or launch configurations):

1. Export only the required artifacts from Eclipse/STS.
2. Place the exported files in this directory with a short comment describing their purpose.
3. Keep files generic so they work on any workstation. Avoid user-specific paths or credentials.
