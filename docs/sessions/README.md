# Calendario de sesiones

Esta carpeta agrupa toda la documentación cronológica de las sesiones de BizFlow ERP. Cada subcarpeta sigue el formato `AAAA-MM` y contiene los archivos diarios con el prefijo de fecha `AAAA-MM-DD` para facilitar la localización rápida.

## Cómo navegar

- Revisa el índice mensual correspondiente para obtener una vista rápida del contenido y los temas tratados.
- Utiliza los enlaces directos incluidos en las tablas para abrir cada documento individual.
- Todos los archivos comienzan con la línea `**Fecha:**` para dejar claro el día de trabajo al que pertenecen.

- [2026-01](2026-01/README.md): Cierres y resúmenes finales de la sesión 6.
