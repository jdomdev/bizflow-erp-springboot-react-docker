## ⚡ Cinco minutos para entender ExpenseNoteApp

### ¿Qué es ExpenseNoteApp?
ExpenseNoteApp es una plataforma web para registrar y aprobar gastos corporativos. Las personas usuarias registran gastos, los managers revisan y los administradores supervisan el sistema completo.

### ¿Qué funciona hoy? ✅
- **Registro e inicio de sesión:** rutas `/api/v1/auth/signup` y `/api/v1/auth/login` activas.
- **Seguridad con tokens JWT:** emisión y validación de tokens en cada petición protegida.
- **Control por roles:** ADMIN, MANAGER y USER con permisos diferenciados.
- **Base de datos persistente:** PostgreSQL con volúmenes Docker.
- **Infraestructura en contenedores:** `docker-compose up -d` levanta frontend, backend y base de datos.

### Próximos entregables 📋
- Implementar dashboard de bienvenida.
- CRUD de gastos y flujos de aprobación.
- Reportería y métricas.

## ⚙️ Puesta en marcha (5 minutos)

```bash
# 1. Clona el repositorio
git clone https://github.com/yourusername/ExpenseNoteApp.git
cd ExpenseNoteApp

# 2. Levanta los servicios con Docker
docker-compose up -d

# 3. Observa los logs (opcional)
docker-compose logs -f

# 4. Acceso
# Frontend: http://localhost
```

## 🆘 Resolución rápida de problemas

### "La aplicación no responde"
```bash
docker-compose ps
docker-compose logs backend
```
Si persiste, ejecuta:
```bash
docker-compose down -v
docker system prune -a -f --volumes
docker-compose up -d --build
```

### "El login falla"
1. Comprueba que el backend está `healthy`.
2. Repite la prueba con `curl`.
3. Consulta `2025-11-27-5-debugging-guide.md` → Error 6 (token JWT inválido).

### ¿Necesitas más ayuda?
- Lee `2025-11-27-5-debugging-guide.md`.
- Abre un ticket interno o issue en GitHub.
