
### 2.2 Flujo de Recreación

Cada `make recreate-*` ejecuta:
1. Regeneración de SQL bootstrap desde secrets
2. Eliminación de contenedores y volúmenes
3. Construcción de imágenes base
4. Inicio de servicios (DB, backend, frontend)
5. Ejecución de seeders

## 6. Hallazgos Técnicos

### 6.1 Usuario de PostgreSQL

El usuario de la base de datos no es el estándar `postgres`, sino:
- DEV: `erp_dev_user`
- TEST: `erp_test_user`
- PROD: `erp_prod_user`

Para ejecutar comandos SQL dentro del contenedor:
```bash
docker exec <container> sh -c 'PGUSER=$POSTGRES_USER psql -d <db> -c "<query>"'
```

### 6.2 Nombres de Tablas

Las tablas usan nombres en **singular**, no plural:
- `role` (no `roles`)
- `position` (no `positions`)
- `expense_user` (no `users`)
- `employee` (no `employees`)
- `payroll` (no `payrolls`)
- `expense` (no `expenses`)
