## 3. Corrección de Rutas API en Frontend

### 3.1 Problema Detectado
Los endpoints del frontend no coincidían con los del backend:
- Frontend usaba `/payroll` → Backend esperaba `/payroll/`
- Frontend usaba `/employees` → Backend esperaba `/employee/`

### 3.2 Correcciones en `frontend/src/services/api.js`

```javascript
// ANTES
export const payrollService = {
  getAll: () => apiClient.get('/payroll'),
  getById: (id) => apiClient.get(`/payroll/${id}`),
};

// DESPUÉS
export const payrollService = {
  getAll: () => apiClient.get('/payroll/'),
  getById: (id) => apiClient.get(`/payroll/${id}`),
  getByUserId: (userId) => apiClient.get(`/payroll/user/${userId}`),
  getByEmployeeId: (employeeId) => apiClient.get(`/payroll/employee/${employeeId}`),
};

// ANTES
export const employeeService = {
  getAll: () => apiClient.get('/employees'),
  ...
};

// DESPUÉS
export const employeeService = {
  getAll: () => apiClient.get('/employee/'),
  getById: (id) => apiClient.get(`/employee/${id}`),
  update: (id, data) => apiClient.put(`/employee/${id}`, data),
};
```

## 7. Explicación OAuth/SSO para Producción

Se explicó al usuario la diferencia entre autenticación por contraseña (actual) y OAuth/SSO para producción:

### Flujo OAuth 2.0
```
Usuario → Identity Provider (Entra ID/Okta/Auth0) → Backend → JWT
```

### Ventajas de OAuth/SSO
- Single Sign-On con credenciales corporativas
- MFA/2FA gestionado por el IdP
- Auditoría centralizada
- Desprovisioning automático

### Proveedores Recomendados
- Microsoft Entra ID (Azure AD)
- Okta
- Auth0
- Keycloak (open source)
